# Geo-Calculator

Geo-Calculator is a high-precision, web-based geospatial measurement application designed to calculate distances, areas, perimeters, road routes, and live GPS tracks. It is specifically optimized for both desktop and mobile users, featuring a clean glassmorphism UI and a dedicated precision magnifier for accurate marker placement.

## 🚀 Features

* **Multi-Mode Measurements**:
* **Distance**: Precise point-to-point measurements with segment-by-segment breakdowns.
* **Area**: Calculate polygon areas with automatic conversion into local land units (Shatangsho/Decimal, Katha, Bigha) and standard units (sq ft, Acre, Hectare).
* **Perimeter/Loop**: Measure closed loops with support for multiple rounds.
* **Road Distance**: Real-time driving/walking distance calculations via OSRM integration.
* **GPS Tracking**: Live tracking of your path, elapsed time, and average travel speed.


* **Precision Tools**: Includes a specialized "Magnifier Box" that assists in placing markers accurately even on touch devices.
* **Responsive Design**: Seamlessly adapts from desktop sidebars to mobile-optimized bottom sheets.
* **Modern UI**: Built with Tailwind CSS and Leaflet.js for a modern, fluid experience.

## 🛠 Tech Stack

* **Frontend**: Tailwind CSS
* **Map Engine**: Leaflet.js
* **Routing API**: OSRM (Open Source Routing Machine)
* **Icons**: FontAwesome

## 💻 How to Run

1. Clone this repository: `git clone <your-repo-url>`
2. Open `index.html` directly in your browser.
3. No build step is required!
